# M13 — 1.5.3 中文默认 + 英文可切换，删除其他 Web 语言包（2026-11-03）

## 目标与范围

本记录更新 M9/M12 中的早期 1.5.3 状态：**当前 1.5.3 不再是 27+ 语言包并存，而是「简体中文（默认）+ English（可切换）」**。保留登录页、快速设置页和系统设置页原有的语言切换 UI，并保留后端 `/locale?form=lang` 读写 API，不是“前端看起来是中文但后端永远只有英文”的硬编码方案。

- 官方固定构建基线：Archer AX12 RU v1.0 `1.5.0 Build 20260605`，SHA-256 `50b09cbc1f18140cd18ebf7fbe611851ab98e21b05d67303307673b5de5003c9`。
- 与 1.5.2 相比：继续保留 1.5.2 已验收的 WAN 内核、owner RSA 验签和 LAN SSH；**只有 1.5.3** 应用语言节省空间的补丁。
- `tools/firmware/patches/zh_cn_en.py` 独立实现本补丁，`v1_5_3.py` 在加入中文 r3 资源后调用它。
- 保留唯一 Web 语言文件 `www/webpages/locale/zh_CN/index-AX12r3.js.gz`，删除 27 个其他 Web 语言目录及多余的旧中文 r2。**英文 Web 翻译已经嵌入主 JS 的 `en_US` 字典 `Hl`，无需单独的 `en_US` 目录**。
- Web `update-store-DnZhtCy9.js.gz` 的语言动态加载器只枚举 `zh_CN` 和内置 `en_US`；`availableLanguages` 只列出简体中文和 English。保留 `changeLanguage` 的原生 API 行为，切换后立即加载所选语言并持久保存。
- 不触碰登录页 `index-HhSH241k.js.gz`、快速设置页 `index-DtHn6Ijf.js.gz`、系统设置页 `index-MrF7bc_q.js.gz`：原有的语言切换入口全部保留，由共同的 `availableLanguages` 数据源限制为两个选项。

## 后端默认语言、旧配置继承和恢复出厂

官方 SquashFS 的 `/etc/config/locale` 默认是 `en_US`。修改这个只读 RootFS 内的 UCI 模板：

```uci
config global sysinfo
    option force   'false'
    option default 'zh_CN'
    option locale  'zh_CN'
```

`force=false` 是有意保留：后续用户可以在浏览器中手动切换为英文，并通过原生 `/locale?form=lang` 接口保存。为了处理升级时旧 1.5.2 overlay **继承英文** 的情况，加入 `etc_ro/init.d/ax12-owner-locale`，链接为 `etc/rc.d/S95ax12-owner-locale`。首次进入 1.5.3 时：

1. 检查可选 UCI 字段 `locale.sysinfo.owner_153_locale_init`（注意 UCI 命名是 `config global sysinfo`，所以名字是 `sysinfo`，不是 `global`）。
2. 如果尚未执行过迁移，则写入 `locale.sysinfo.default=zh_CN`、`locale.sysinfo.locale=zh_CN`、`locale.sysinfo.force=false` 和 `locale.sysinfo.owner_153_locale_init=1`，一次 `uci commit locale`。
3. 后续启动若标记为 1，就**不再修改**用户选择。用户切换至英文后，重启保持英文。
4. 恢复出厂设置理论上使 overlay 回到只读 RootFS 默认配置 `zh_CN`，迁移标记也随之清除；首次启动脚本再次初始化。**真实设备的出厂恢复路径没有在本次改动中执行**，仅在模拟 UCI 环境测试了三种状态。

如果上游后端因厂商平台配置/启动顺序覆盖 UCI 语言，则真实设备还可能出现差异；需实机检查 `/locale?form=lang` 和 `uci show locale` 才能把「恢复出厂必然默认中文」标记为最终验收通过。此实现不修改架构相关的 LuaJIT `locale.lua` 字节码，避免不必要的 ABI/版本风险。

## 离线验收

测试构建机为独立 Linux 环境，**没有向路由器写 Flash、SSH 连接或重启**。官方原始 ZIP / BIN SHA-256 经过独立比对。

1. `python3 build.py --version 1.5.3`：**PASS**，输出 RootFS `10,121,219` 字节、Cloud 签名输入 256 字节，SHA、AES、Realtek seal、分区边界及无 Bootloader 更新项检查通过。
2. 使用独立一次性 RSA-2048 测试密钥 `--owner-public ... --sign-key ...`：**PASS**，完整 RSA-PSS 签名、验签、AES 解密、RootFS 回读。测试签名镜像**不适用于**用户当前路由器。
3. `verify_bilingual.py`：**PASS**，检查只保留 `zh_CN` Web 文件、内置英文加载器、两项可选语言、三个原语言切换入口、UCI 默认值及首次启动脚本。
4. 修改后的 Vite `update-store` JS 模块通过 Node.js v22 `--check`：**PASS**。
5. 使用模拟 `uci` 命令对首次启动脚本分别测试“旧英文配置迁移成中文”“后来手动选择英文在第二次启动保留”“出厂模板还原中文并重新初始化”：**全部 PASS**。不等价于实际硬件上的 Reset/浏览器测试。
6. `verify_patch_chain.py`：**PASS**，旧版 1.5.0/1.5.1/1.5.2 补丁效果不变，仅 1.5.3 出现预期语言配置、初始化脚本、语言资源移除和 Web loader 变化。
